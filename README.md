# Student Score Prediction using Linear Regression

## Project Overview
This is a small Machine Learning practice project using Linear Regression.

The objective is to predict students' final scores based on:
- Study Hours
- Attendance Percentage
- Previous Score

## Dataset Information
- Total Records: 200
- Total Features: 4
- Missing Values: 0
- Duplicate Records: 0

## Tools and Libraries
- Python
- Pandas
- NumPy
- Scikit-learn

## Project Workflow
1. Load the dataset
2. Check dataset information
3. Check missing and duplicate values
4. Separate input features and target variable
5. Split data into training and testing sets
6. Train the Linear Regression model
7. Predict student final scores
8. Evaluate model performance

## Model Performance

| Metric | Result |
|---|---:|
| R² Score | 0.9033 |
| Mean Squared Error | 16.8591 |
| Root Mean Squared Error | 4.1060 |

## Model Features
- Study Hours
- Attendance Percentage
- Previous Score

**Target Variable:** Final Score

- Understanding Linear Regression
- Practising train-test split
- Training a regression model
- Making predictions
- Evaluating model performance
- Understanding model coefficients
